# TODO Notes Web

A local-first task notebook built with Vite, Svelte, and TypeScript.

## Live Demo

[Open TODO Notes Web](https://rodrigoviladegut-cr.github.io/todo-notes-web/)

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run check
npm run test:unit
npm run test:e2e
npm run build
```

Pushes to `main` are automatically checked, built, and deployed to GitHub Pages by
`.github/workflows/deploy-pages.yml`.
